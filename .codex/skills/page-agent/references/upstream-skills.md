# Upstream `.agents/skills`

The `alibaba/page-agent` repository contains project-maintenance skills under `.agents/skills/`:

- `git-cleanup`
- `maintain-model-list`
- `pre-impl-discussion`
- `submit-pr-from-current-changes`
- `update-changelog`

These are useful when working inside the Page Agent repository itself. In this collection they can be synced as separate Codex skills under `.codex/skills/page-agent-*` to avoid name collisions with generic skills.

Use these only when the task is actually about maintaining or contributing to `alibaba/page-agent`.
