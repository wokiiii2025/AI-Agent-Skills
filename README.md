# AI Agent Skills

A syncable collection of personal Codex / AI-agent skills. Skills are stored under `.codex/skills/` so agents can install or mirror them consistently.

## Install

### PowerShell

```powershell
git clone https://github.com/wokiiii2025/AI-Agent-Skills.git
cd AI-Agent-Skills
./scripts/install.ps1
```

### Bash

```bash
git clone https://github.com/wokiiii2025/AI-Agent-Skills.git
cd AI-Agent-Skills
bash scripts/install.sh
```

## Auto sync

- Git-backed skills are listed in `skills-sources.json`.
- Run `python scripts/sync_skills.py` to refresh them from upstream.
- GitHub Actions workflow `.github/workflows/sync-skills.yml` runs daily and can also be triggered manually.
- Local snapshot skills stay unchanged until manually updated because no upstream repository was detected in local metadata.
